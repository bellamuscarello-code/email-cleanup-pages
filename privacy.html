Privacy Policy

Last updated: September 28, 2026

Email Cleanup is a personal tool used only by its developer to manage the developer's own Gmail accounts. It is not made available to other users.

Data accessed

With the owner's consent, the app uses the Gmail API (scope: gmail.modify) to read message metadata and content, apply labels, and move messages to Trash in the owner's own accounts.

Data use and storage

Email data is processed only to decide how to organize the owner's mailbox. It is not sold, shared with, or disclosed to any third party, and is not used for advertising. Any records kept (such as an action log) remain private to the owner.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
